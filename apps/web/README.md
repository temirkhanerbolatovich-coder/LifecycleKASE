# Web boundary

This directory will contain the Next.js administrator and investor interfaces. The web application will request unsigned transactions from the API and submit them through the connected wallet. Client-side validation will complement, but never replace, API and on-chain validation.

The initial transparent app mark is stored at `public/brand/lifecyclekase-mark.png`. It is a raster logo concept for the future app icon and header; the web application is not yet implemented or wired to this asset. The product name should be rendered as UI text beside the mark rather than embedded in the image.
