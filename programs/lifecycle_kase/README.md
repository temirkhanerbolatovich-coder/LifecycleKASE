# Anchor program boundary

This directory will contain the LifecycleKASE Anchor program. The program will enforce instrument authority, action state transitions, snapshot commitments, per-entitlement replay protection, payment transfers, token burns, and execution receipts.

The program scaffold is intentionally deferred until the Rust, Solana, and Anchor versions are selected and recorded. This avoids committing an unbuildable or unverified generated project.
